| Begriff | Bedeutung |
| --- | --- |
| **Evolution** | Veränderung von Lebewesen über viele Generationen |
| **Artkonstanz** | ältere Vorstellung: Arten verändern sich nicht (z. B. Cuvier) |
| **Lamarckismus** | Lamarcks Erklärung (1809): Gebrauch/Nichtgebrauch von Organen und Vererbung erworbener Eigenschaften – heute widerlegt |
| **Population** | alle Lebewesen einer Art in einem Gebiet, die sich miteinander fortpflanzen |
| **Variation** | Unterschiede zwischen den Individuen einer Art |
| **Natürliche Selektion** | Auslese durch die Umwelt: Wer nützliche Merkmale hat, überlebt eher und hat mehr Nachkommen |
| **Fitness** | Fortpflanzungserfolg – nicht Stärke |
| **Angepasstheit** | ein Merkmal passt zu einer bestimmten Umwelt; ändert sich die Umwelt, kann es zum Nachteil werden |
| **Gemeinsamer Vorfahr** | ausgestorbene Art, aus der sich zwei oder mehr Linien entwickelt haben |
| **Stammbaum** | Darstellung der Verwandtschaft: Je jünger die Verzweigung, desto näher verwandt |
| **Übergangsform** | Fossil mit Merkmalen zweier Gruppen, z. B. *Tiktaalik* (Fisch und Landwirbeltier) |
| **Homologie** | gleicher Bauplan aus gemeinsamer Abstammung (Arm, Walflosse, Fledermausflügel) |
| **Analogie** | gleiche Aufgabe, aber anderer Bauplan (Flügel von Vogel und Biene) |
| **Mutation** | zufällige Veränderung im Erbgut – zufällig in Bezug auf ihren Nutzen |
| **Resistenz** | Unempfindlichkeit, z. B. von Bakterien gegen ein Antibiotikum |
| **Synthetische Evolutionstheorie** | Verbindung von Darwins Theorie mit der Genetik (1930er/40er-Jahre) |
