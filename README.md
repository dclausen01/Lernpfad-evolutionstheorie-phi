# Lernpfad Evolutionstheorie (Philosophie, Jg. 11)

Selbstlern-Pfad zu den **Grundzügen der Evolutionstheorie** – 2 Unterrichtsstunden, ohne Abgabe, mit Selbstkontrolle
(Kurz-Checks, Checklisten, aufklappbare Lösungen). Nur Biologie – die philosophische Anknüpfung folgt im Unterricht.

| Stufe | Module |
| --- | --- |
| 🌱 Darwins Theorie (45 min) | G1 Vor Darwin – Lamarck · G2 Variation, Selektion, Vererbung · G3 Was heißt „Fitness“? |
| 🚀 Abstammung und Belege (45 min) | V1 Gemeinsame Abstammung · V2 Belege für die Evolution · V3 Darwin heute + Abschluss-Check |

- **Web-Version:** liegt in `docs/` und wird über GitHub Pages veröffentlicht (Einstellungen › Pages › Branch, Ordner `/docs`)
- **Neu bauen:** `./docs-bauen.sh` – baut die Web-Version und kopiert sie nach `docs/`
- **Quellen mit Prüfstatus:** `quellen.yaml`
- Gebaut mit dem [Lernpfad-Baukasten](https://github.com/dclausen01/lernpfad-baukasten):
  Inhalte nur in `kurs.yaml`, `module/`, `seiten/`, `medien.yaml` ändern, nie in `docs/` oder `ausgabe/`.
